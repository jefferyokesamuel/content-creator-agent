# Content Production — Optimization Checklist

## Pre-Publish Quality Gates

### Keyword & SEO
- [ ] Primary keyword appears naturally 3-5 times (not stuffed)
- [ ] Title tag contains primary keyword, under 60 characters
- [ ] H1 is different from title tag, keyword-rich, reads naturally
- [ ] At least 2-3 H2s contain secondary keywords or related phrases
- [ ] Primary keyword appears in first 100 words
- [ ] URL slug is short, keyword-first, no stop words
- [ ] Meta description: 150-160 chars, includes keyword, ends with action/hook
- [ ] OG title / OG description set (can differ from meta)
- [ ] Canonical URL set

### Readability
- [ ] Average sentence length: 15-20 words (mix it up)
- [ ] No paragraph over 4 sentences
- [ ] No unexplained jargon (for non-expert audiences)
- [ ] Active voice throughout (flip passive constructions)
- [ ] Readability score ≥ 70

### Structure
- [ ] Intro delivers on the headline's promise
- [ ] Every H2 section earns its place (cut if not)
- [ ] At least 2 examples or concrete illustrations
- [ ] Conclusion feels earned, not tacked on

### Sources & Claims
- [ ] Every factual claim has a source or is clearly labeled as opinion
- [ ] No "studies show" or "many companies" without citation
- [ ] Data points include specific numbers (not vague claims)

### Links
- [ ] 2-4 internal links minimum
- [ ] Link from high-traffic existing pages to this piece
- [ ] Link from this piece to related existing content
- [ ] Anchor text describes the destination (not "click here")

### Visuals
- [ ] At least one image, table, or visual element breaks up text
- [ ] Image alt text is descriptive, includes keyword where natural

### Final
- [ ] Word count is within 10% of target
- [ ] Intro doesn't start with a cliché
- [ ] CTA exists and matches the piece's goal
- [ ] All internal links work
