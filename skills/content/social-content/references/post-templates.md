# Post Templates for Social Platforms

## TikTok Caption Templates

### Template 1: Hook + Value + CTA
```
[1-line hook that stops the scroll]

[2-3 sentences of value / content summary]
[Line break]
[1-line CTA]
[3-5 hashtags]
```

**Example:**
```
the secret to editing 10x faster isn't what you think

i spent 6 months testing every shortcut, tool, and workflow. turns out the best one was staring me in the face the whole time. here's what actually works 👇

follow for more editing tips 🎬
#videoediting #filmmaking #productivityhacks
```

### Template 2: Storytime
```
[relatable setup — 1 line]

[3-5 sentence story with emotional arc]
[twist or lesson]
[CTA]
[3-5 hashtags]
```

### Template 3: Tutorial / How-To
```
[benefit hook — "want [result]? do this"]

step 1: [action]
step 2: [action]  
step 3: [action]

[pro tip / shortcut]
[save this for later CTA]
[3-5 hashtags]
```

## Instagram Caption Templates

### Template 1: Story + Lesson
```
[hook — 1 line]

[3-5 paragraph story]
[line break]
[lesson / takeaway]
[line break]
[CTA + 5-10 hashtags]
```

### Template 2: Value Bomb List
```
[benefit hook — 1 line]

[number] things I learned about [topic]:

1. [point]
2. [point]
3. [point]

[save/share CTA]
[5-10 hashtags]
```

## LinkedIn Post Templates

### Template 1: Hot Take
```
[bold contrarian statement — 1-2 lines]

[optional expander — 1 sentence]

[numbered list — 3-6 points with bold headers + 2-3 sentence explanation each]

TAKEAWAY: [one-liner]

[CTA — "Follow me for more" / "What do you think?"]
```

### Template 2: Personal Story
```
[emotional hook]

[3-4 paragraph story with business lesson]

[key insight / framework]

[CTA]
```

## Twitter/X Thread Template

```
1/ [hook tweet — must be standalone, makes people want more]

2/ [context / setup]

3/ [main point 1]

4/ [main point 2]

5/ [main point 3]

6/ [main point 4]

7/ [conclusion / takeaway]

8/ [CTA — follow, retweet, reply]
```
