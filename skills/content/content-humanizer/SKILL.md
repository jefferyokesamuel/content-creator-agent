# Content Humanizer

Makes AI-generated content sound genuinely human — not just cleaned up, but alive. Use when content feels robotic, uses too many AI clichés, lacks personality, or reads like it was written by committee.

## When to Use

- Content "sounds like AI"
- Generic, committee-speak tone
- Lacks personality or voice
- Reads stiff or overly formal
- User says "make it more human," "add personality," "it feels generic"

## AI Tell Checklist

Run through these and remove each one:

### Cliché Phrases to Eliminate
- "In today's digital landscape" / "In today's fast-paced world"
- "Let's dive in" / "Let's take a deep dive"
- "It's not just about X, it's about Y"
- "The answer might surprise you"
- "Game-changer," "revolutionary," "next-level"
- "Unlock your potential"
- "I get it" / "I hear you" (when overused)
- "At the end of the day"
- "That being said"
- "Navigating the complexities of"

### Structural AI Tells
- Every paragraph is exactly 2-3 sentences — vary it
- Every sentence is perfectly grammatical — add fragments, contractions
- Every point is a three-item list — break the pattern
- No personality / no opinion — add a hot take
- Overly formal transitions (Furthermore, Moreover, Consequently)
- First paragraph starts generic instead of specific

## How to Humanize

### 1. Inject Voice
- Use contractions (don't, can't, it's, there's)
- Start sentences with "And," "But," "Or," "So" occasionally
- Add a personal opinion: "Here's the thing..." / "Honestly?" / "I'll be straight with you"
- Use metaphors, analogies, and concrete examples, not abstractions

### 2. Add Rhythm Variation
- Mix short punchy sentences with longer flowing ones
- Use sentence fragments for emphasis: "Simple. Direct. Powerful."
- Break the list pattern — sometimes deliver 2 points, sometimes 4
- End sections with a punchy takeaway, not a summary

### 3. Remove Polish Overkill
- Delete unnecessary adverbs (simply, essentially, basically, ultimately)
- Remove hedging (might, could, perhaps, potentially — unless genuinely uncertain)
- Replace passive voice with active: "The data was analyzed" → "We analyzed the data"

### 4. Add Authenticity Markers
- Personal anecdotes (even short ones)
- Acknowledged uncertainty: "I'm not 100% sure on this, but..."
- Self-deprecation where appropriate
- Specific details that only someone in-the-know would include

## TikTok-Specific Humanization

For short-form video scripts:
- Write how people talk, not how people write
- Use verbal pauses: "OK so..." / "Right?" / "You know what I mean?"
- Keep sentences under 10 words where possible
- End sentences with energy, not trailing off
- Read it aloud — if it doesn't sound like something you'd say to a friend, rewrite it
